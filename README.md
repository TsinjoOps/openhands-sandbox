# openhands-sandbox

Isolated public sandbox for **agent Git/GitHub workflow qualification**. The repository name is retained for historical continuity because its first qualification work targeted OpenHands.

Current uses include:

- deterministic GitHub branch/PR/CI experiments;
- OpenCodeReview qualification and decision mechanics;
- historical OpenHands Git/PR evidence;
- OpenCode GitHub-first Producer -> Debugger qualification (Issue #19 / Draft PR #20).

No production or customer data belongs in this repository. Synthetic qualification PRs may intentionally remain Draft/unmerged as evidence.
